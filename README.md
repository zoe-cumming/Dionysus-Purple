## Equipment
- **nRF52840 DK** (Base node, nanoPB encoder)
- **Thingy:52** (Audio, light and temperature sensor node)
- **ESP32C3 DevkitM** (Servo controller)
- **Disco L475 IOT01** (Servo controller)
- **M5Core2** (Display)
- **ESP32 S3 EYE** (Image collection node)
- **PC** (ML implementation, MQTT comms, nanoPB decoder)
- **MQTT Server** (Sensor and setting data transmission)
